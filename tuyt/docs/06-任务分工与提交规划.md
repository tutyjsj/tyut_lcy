# 环境网格化综合管理系统 — 任务分工与提交规划

> 太原理工大学 课程设计/毕业设计项目（TYUT）
> 
> 团队规模：4人 | 总提交次数：20次（每人5次） | 组长承担约55%后端工作量

---

## 一、分工总览

| 人员 | 角色 | 技术栈侧重 | 核心职责 | 代码占比 |
|:--:|------|------|------|:--:|
| **A（组长）** | 后端全栈 | Spring Boot / MyBatis-Plus / MySQL / Redis | 全部后端模块（23个Entity、22个Mapper、22个Service、15个Controller、框架+公共模块、数据库设计） | **~55%** |

## 二、依赖关系图

```

  ├── A1: 后端项目骨架 + 数据库设计     [后续所有人依赖]
```
